## 使用 GitHub Pages 发布

1. 将本文件夹内的全部内容上传至公开仓库根目录，确保 index.html 直接位于根目录。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。
4. 等构建完成后，在 Pages 设置页复制正式网址。

不要直接上传 ZIP，也不要在根目录外再套一层文件夹。
